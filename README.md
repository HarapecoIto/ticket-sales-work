# チケッティング処理自動化ツール

チケッティング処理を自動化するためのツール。

データベースに収納されたチケット売り上げをLINEなどに自動的に報告する。

このNext.jsアプリはvercelにデプロイされ、自動報告等のbatch処理はcronなどで行われる。

cronはvercelのAPI Routeとして設定される。

vercelのAPI Routeは実行時間には、
Proプライン以上でも最大60秒という強い制約があるので、時間のかかるものは、github actionsの定期実行など
他のツールで行う。

今はまだ実装されていないが、このnext.jsは各種設定の確認及び変更など、
ログイン機能を持ったwebサイトとしても使われる。

データベースへのチケット売り上げの収集は、
playwrightによるスクレイピングで行われる。
この処理は時間がかかる上に、
vercelの実行環境は解凍状態で250MBまでという制限が全てのプランであり、
この制限をクリアしてplaywrightを実行するのは無理ではないが工夫がいる。

よって、この処理はgithub actionsの定期実行で行う。

# マイグレーション

マイグレーションは、package.jsonにあるコマンドの db:push:local で行う。
